# เว็บควบคุมปลั๊ก 4 ช่อง

เว็บไซต์จริง ไม่มีการจำลองสถานะเปิด–ปิด ต้องใช้เฟิร์มแวร์ที่เชื่อมต่อ Cloudflare ตาม PROTOCOL.md

สำคัญ: SmartPlugESP8266.ino เดิมเป็นเว็บภายในบ้านเท่านั้น ยังเชื่อมต่อระบบกลางนี้ไม่ได้ ต้องปรับเฟิร์มแวร์ก่อนควบคุมจากนอกบ้าน

## ติดตั้ง Cloudflare Worker ของคุณ

1. ติดตั้ง Node.js รุ่น LTS และเปิด Terminal ในโฟลเดอร์นี้
2. รัน `npm install` แล้ว `npx wrangler login` เข้าบัญชี Cloudflare
3. ตั้งชื่อ Worker ใน wrangler.jsonc ตามต้องการ เช่น smart-plug
4. รันคำสั่งต่อไปนี้ทีละคำสั่ง แล้วกรอกรหัสเมื่อโปรแกรมถาม (อย่าใส่รหัสในซอร์สโค้ด)

```
npx wrangler secret put WEB_PASSWORD
npx wrangler secret put DEVICE_KEY
npx wrangler secret put SESSION_SECRET
npm run deploy
```

WEB_PASSWORD: รหัสเข้าเว็บ เลือกรหัสยาวที่คาดเดายาก

DEVICE_KEY: กุญแจสำหรับบอร์ด แยกจากรหัสเว็บ แนะนำค่าสุ่มอย่างน้อย 32 ตัวอักษร

SESSION_SECRET: กุญแจลงลายมือชื่อการเข้าสู่ระบบ ใช้ค่าสุ่มอย่างน้อย 32 ตัวอักษร แยกจากสองค่าข้างต้น

หาก wrangler แจ้งว่า Worker ยังไม่มีอยู่ ให้รัน `npm run deploy` ครั้งแรกก่อนตั้ง secrets จากนั้นตั้งทั้งสามค่าและ deploy อีกครั้ง หน้า API จะปฏิเสธคำสั่งจนตั้งครบ

5. จะได้ https://smart-plug.ชื่อบัญชี.workers.dev เปิดลิงก์นี้แล้วกรอก URL เดียวกันกับ WEB_PASSWORD
6. หรือเปิดหน้าแดชบอร์ดที่เผยแพร่ไว้และใส่ URL Worker ของคุณ เว็บแดชบอร์ดจะเชื่อม API ข้ามโดเมนที่อนุญาตใน DASHBOARD_ORIGIN
7. อัปโหลดเฟิร์มแวร์ที่รองรับ PROTOCOL.md แล้วทดสอบด้วยไฟแรงดันต่ำ ตรวจสถานะ เปิด/ปิด และการบันทึกก่อนต่อเครื่องใช้จริง

ไม่ต้องมี KV, R2, D1 หรือ MQTT เพิ่ม ใช้ Durable Object แบบ SQLite หนึ่งตัว

## พฤติกรรม

- บอร์ดไม่ออนไลน์: สวิตช์กดไม่ได้ แสดงสถานะเป็นขีด เพราะยังยืนยันปัจจุบันไม่ได้
- ส่งคำสั่งแล้ว: สถานะยังคงค่าที่บอร์ดยืนยันครั้งล่าสุดจนได้รับ ACK ที่ตรงกับคำสั่ง
- คำสั่งรอยืนยันสูงสุด 10 วินาที ไม่เก็บคำสั่งเพื่อเปิดอุปกรณ์เมื่อบอร์ดกลับออนไลน์ภายหลัง
- เปิด–ปิดด้วยมือยกเลิกนับถอยหลังของช่องนั้น ตามเฟิร์มแวร์เดิม
- ชื่อ/อีโมจิ/ตารางเวลา: บอร์ดต้องบันทึกสำเร็จก่อนตอบ ACK; เว็บกลับหน้าหลักและแจ้งสำเร็จ 3 วินาที
- บันทึก config ส่งข้อมูลครบช่อง รวมเวลานับถอยหลังที่เหลือ โดยปัดเป็นนาที จึงอาจคลาดเคลื่อนได้ไม่ถึงหนึ่งนาทีเมื่อบันทึกชื่อหรือตาราง
- ตารางรายวันให้บอร์ดทำเองด้วยเวลาไทย UTC+7 แม้หน้าเว็บปิดหรืออินเทอร์เน็ตหลุดหลังเทียบเวลา
- หลังรีสตาร์ต: เริ่มปิดทุกช่อง นับถอยหลังยกเลิก ตารางรายวันรอซิงก์เวลาและเริ่มที่นาทีตรงกันครั้งถัดไป
- สถานะเป็นการยืนยัน GPIO จากเฟิร์มแวร์ ไม่ตรวจหน้าสัมผัสรีเลย์หรือกระแสไฟของเครื่องใช้
- การเข้าสู่ระบบจำกัด 10 ครั้งต่อ IP ต่อ 10 นาที Token อายุ 12 ชั่วโมง; ออกจากระบบลบ token จากเบราว์เซอร์ แต่ token ที่ถูกคัดลอกไปก่อนหน้านั้นยังมีอายุจนหมด

## การตรวจสอบ

`npm test` ทดสอบคำตอบที่ตรง/ไม่ตรง คำตอบหมดเวลา และบอร์ดออฟไลน์

ยังไม่ได้ทดสอบกับ ESP8266 จริงหรือ Deploy backend เข้าบัญชี Cloudflare ของคุณ

เมื่อใช้ผ่าน Worker URL ของตัวเอง ใช้หน้าเว็บและ API ในโดเมนเดียวกันได้ทันที
